# Databento MCP 1.3.2 — установка на Windows

Пакеты содержат исправление получения последней доступной исторической котировки.
`get_futures_quote` возвращает `dataMode: historical`, время котировки, её возраст
и `availableEnd`. Исторические данные могут отставать от текущего времени.
Для настоящего live используется отдельный `get_live_futures_quote`.

## Claude Desktop

1. Полностью закройте Claude Desktop.
2. Откройте `databento-claude-1.3.2.mcpb` двойным щелчком. Если Windows не узнаёт
   формат, выберите «Открыть с помощью → Claude Desktop».
3. Подтвердите обновление Databento MCP. Если приложение запросит ключ Databento,
   введите его в защищённое поле настроек расширения. Включите расширение.
4. При необходимости импортируйте `market-data-skill-1.3.2.zip` через управление
   скиллами. Уже установленный скилл можно обновить этим ZIP.
5. Откройте новый чат и выполните проверку ниже.

## ChatGPT Work / настольный клиент, Windows x64

1. Полностью распакуйте `databento-chatgpt-windows-1.3.2.zip` в обычную папку.
   Не запускайте установщик прямо из окна ZIP.
2. Закройте ChatGPT. Дважды щёлкните `Install-ChatGPT.cmd`.
   Права администратора, установка Node.js и команды в терминале не нужны.
3. При первой установке введите Databento API key в появившемся окне. Ввод скрыт.
   При обновлении ранее сохранённый ключ используется автоматически.
4. Откройте ChatGPT, затем Plugins → личный каталог → Databento MCP → Install.
   Если плагин уже установлен, обновите/переустановите его из личного каталога.
5. Создайте новый локальный чат Work и включите Databento MCP.

Установщик сохраняет остальные записи личного каталога. Предыдущая версия и
копия каталога находятся в `%USERPROFILE%\.codex\databento-backups`.
Ключ хранится отдельно от плагина, в локальном
`%USERPROFILE%\.databento-mcp\.env`; не пересылайте этот файл.
Сохранённый ключ можно заменить в этом файле и перезапустить ChatGPT.
Это локальный пакет для Windows x64: работа в браузере и Windows ARM64 этой
поставкой не проверялась.

## Проверка после установки

В новом чате попросите:

> Покажи доступные инструменты Databento. Вызови get_session_info без параметров.
> Затем получи историческую котировку ES через get_futures_quote. Покажи цену,
> время, dataAge, dataMode и availableEnd. Не запускай batch и большие выгрузки.

Первый вызов проверяет локальное подключение без обращения к Databento. Вызов
котировки обращается к Databento с вашим ключом и требует соответствующего доступа.
Не отправляйте API-ключ в чат.

## Что входит в поставку

Для ChatGPT включены сервер, production-зависимости, скилл и Node.js 24.18.1
для Windows x64. Для Claude используется его механизм Node-расширений MCPB.
Файлы `BUILD.json` и `SHA256SUMS.txt` фиксируют исходный коммит и контрольные суммы.
Известные уязвимости production-зависимостей исходной ветки оставлены отдельной
задачей по согласованию с владельцем; эта версия исправляет котировки и упаковку.
